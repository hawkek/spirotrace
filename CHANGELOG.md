# Changelog

All notable changes are listed here. Versions follow semantic versioning.

## Unreleased

- `checks/`: the rule registry and the curated rules (stage 5 and the cohort pass). Every check is a named rule with an id, a layer (input, ocr, range, layout, image, consistency, gli, cohort, free_text, derived), the severities it may raise and a one-sentence rationale; `rules.off` and `rules.layers_off` switch rules off by id or layer; a flag names the observations it rests on and may carry a suggestion the reviewer sees and the rule never applies; `confirm` records agreement. Thresholds, range limits and vocabularies live in one table with their sources. Reading conditions become flags here, never inside reading code: a value flagged by the ocr or range layer as an error leaves the cross-checks, as the old script's unreadable and out-of-range values did. Rules ported from the old script cover ranges and lost decimal points, printed decimals, the table and header reading conditions, physical order of lung volumes, ratios, percent predicted, lower-limit and z-score consistency, pre and post, trials against the summary, trend pages, header fields read on two pages, session quality, the cohort robust-z outlier, and the GLI recalculation (z, LLN, predicted and percent predicted against ranges from the rounding intervals, trial and best-ratio candidates, the second z column). Added as decided: the haemoglobin-correction direction check, repeated trial numbers, the interpretation contradiction and not-read notes, the clipped post trial row quirk, a column empty in nearly every report of a layout demoting its empty-cell checks, and the lab row-template note once per table.
- `rspiro.py` and `rspiro_bridge.R`: the one rspiro bridge. Rscript from `tools.rscript` (never assumed on PATH), inputs and outputs through temporary files, nothing printed; GLI-2012 and GLI global spirometry and GLI 2017 diffusing capacity (TLCO, KCO, VA) at the corners of the age, height and rounding intervals; the bundled script first reproduces the device's own example report. Without Rscript the gli rules are reported as not run, never as passed. A fixed grid of rspiro outputs is a test fixture; the live comparison runs only where Rscript with rspiro is installed.
- `ingest/`: opens each PDF once (the only module that does) and gives every page its words in page-normalised coordinates, grouped into lines and deskewed; a page's own `/Rotate` is applied and a page stored sideways without one is turned by scoring the words formed at each orientation; the dark-pixel fraction is measured for every page and page images are rendered on request. pdfplumber, pypdfium2 and Pillow become runtime dependencies. OCR of pages without a text layer is refused with a message until it is ported.
- `layouts/`: layout-free reading helpers. The token grammar (printed dashes and their OCR forms, a cell holding only `~`, `_` or `=` read as a dash with a condition, letter-for-digit repairs, a leading `~` or `_` as a minus sign, the out-of-range marker), fuzzy phrase finding, a table reader anchored on right edges with rows matched by label and otherwise placed by gap, by order or by a measured height template, labelled header fields, subject and record ids, and a builder turning a cell into a model observation with its value state, ratio fraction and marker (text found but not read can be stored as `unreadable` with the text kept). Reading never sets a severity: what the old script flagged inside reading is a reading condition with a stable code for the rules. Layout-specific code stays outside the package.
- `evaluate/`: reference-sample generator. A sampling frame of record id, layout and feature names; a stratified draw (layout x first precedence feature) with a seed, proportional allocation with a floor per stratum, and the sampling fraction kept on every sampled record; allocation of sampled reports to coders with a fixed overlap per coder pair spread over the layouts, per-coder report counts and per-coder exclusion lists that are never violated (an infeasible design stops with counts only); one blind coding workbook per coder (one sheet per report in a seeded order, record id, layout, start and end time cells, one row per core field with value, value-state dropdown, page and note); a `_CONTAINS_DATA` manifest and a counts-only summary. The console prints counts only and no output file is ever overwritten. openpyxl becomes a runtime dependency.
- `model/`: value model for the extraction store. Fixed vocabularies (value states `value`, `empty`, `dash`, `not_on_page` and `unreadable`; read methods; column roles with distinct pre and post roles; standard parameters with kinds), the observation natural key with its string form (display position 1 is always the Best column), frozen `Record`, `Page` and `Observation` types with exact row round trips, and ratio parsing that stores FEV1/FVC, RV/TLC and FRC/TLC as fractions with the printed form kept. A struck-through value is a readable `value` with the `struck` flag set on the observation, not a value state. Record ids are `11`, `11A` / `11B`, `f` plus eight hex characters of the file hash when the file name gives no subject id, and `-2`, `-3`, ... for further files with the same subject id. `ParameterInfo.site_identifier` marks device serial and software version for the export guard. `never_extract_hits` matches the never-extract words and sign-off phrases as whole words, and a test keeps every parameter name clear of them.
- `config.py`: loads `spiro.toml` and `profiles/<name>.toml` with `tomllib`, validates them against a declared schema (unknown keys refused, profiles limited to switches), fills defaults, and returns one frozen settings object with a hash of the parsed settings.
